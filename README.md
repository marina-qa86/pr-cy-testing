# Проект PR-CY

PR-CY — российская платформа для SEO и интернет-маркетинга. Тестирование  продукта проводилось на production в рамках обучающей стажировки Performance Lab.

## Задачи

- Составляла позитивные и негативные тест-кейсы в TestRail.
- Готовила тестовые данные для ИИ-генераторов: тексты и изображения JPG и PNG разных размеров.
- Проверяла работу SEO-инструментов, проводила функциональное и регрессионное тестирование.
- Тестировала интерфейс в Chrome и Яндекс.Браузере.
- Проверяла API с помощью Swagger и Postman, анализировала ответы и HTTP-коды.
- Оформляла дефекты в Jira: описывала шаги воспроизведения, фактический и ожидаемый результаты, проверяла дубликаты.
- Запускала готовые автотесты, анализировала результаты и вручную перепроверяла упавшие сценарии.
- На тестовых площадках изучала Kibana и Kafka, проверяла запросы в Kafka UI.

## Рабочий процесс

Работала по Scrum в двухнедельных спринтах в команде из 5 разработчиков, 3 тестировщиков и проджект-менеджера.
